## Delivered source-capture behavior

The owned-row census and byte archive remain recoverable when canonical saved
content contains permitted dangling or external references. Private disk-backed
validation records unresolved edges, alias ambiguity, unsupported traversal and
explicit authority exclusions separately. It never discovers arbitrary IDs in
prose or uses a reference to fetch foreign private data, grant access or select a
newer live revision.

Stored-position worker generators use iterative ancestry frames and streamed
checkpoints rather than renderer node/depth or 512-instance limits. Component
contexts deduplicate on disk; identical-context/Action cycles terminate while a
transformed recursive context is explicitly unsupported. Dynamic outputs,
render/media merge formats, formatted media and repeated media interpolation
retain unsupported coverage until exact output adapters exist.

`backup-reference-coverage` v1 pages are part of the sealed manifest. The reserved
`~.backup-coverage:<snapshot UUID>:<16-digit page>` identity is unavailable to
canonical generic Thing creation and validated against the current header/page
sequence. Primitive string validation rejects array/object coercion. Restore
review classifies these as descriptive source coverage and allocates no new user
Thing target. Older readers may reject this new namespace/adapter; updated
readers preserve existing archive compatibility.

Historical notification content uses the canonical approved
`notification-content` v1 projection and shared streaming payload transport as
`backup-notification-content` v1. Stored actor/message fields and historical
creation/update/read/history-only state survive independently. Live profile
enrichment, delivery/provider keys, dedupe authority and secret envelopes are
excluded. Canonical parse/rehash yields and rechecks cancellation, source scope
and authorization after the final range. No notification is re-emitted.

Subscription rows carry only a `backup-source-exclusion` v1 descriptor for live
entitlement authority; no private entitlement payload is read or replayed.
Exclusions are counted in reference evidence, not presented as restored content.
