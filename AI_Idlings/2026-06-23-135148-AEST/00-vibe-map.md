# 2026-06-23 13:51 AEST - Vibe Map

Thingtime feels less like a conventional CRUD app and more like a personal and
public substrate for "things": structured data, identity, intent, records,
links, tools, markets, and civic memory.

The strongest product vibe so far:

- Data should be equally usable by humans, apps, and agents.
- The real API is the product spine. Tests, seed data, UI, and integrations
  should all use the same path.
- Identity should be portable and externally verifiable, but revocation and
  session truth still need server-side checks.
- The interface should stay playful, but the system should become serious:
  audit trails, trust, public records, marketplaces, and coordination.
- Lopu is not just toast UI. Lopu can become the friendly membrane between raw
  structured power and human confidence.

Possible north star:

Thingtime is a GUI, API, identity layer, app store, and public memory system for
structured human intent.

Practical posture:

- Build tiny reliable loops first.
- Make each loop API-addressable.
- Make each loop composable as a "thing".
- Add cryptographic trust and public accountability only where the workflow
  already proves useful.
