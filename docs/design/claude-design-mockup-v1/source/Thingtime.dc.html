FOR DEVELOPERS

Every thing is an API.

Read and write any path over HTTP. Browser sessions and API clients share one revocable, ES256-signed token — and other platforms can verify Thingtime-issued tokens offline via JWKS.

ES256 JWKS httpOnly cookie + Bearer
