Themes are already shareable — give them a home

Wear the internet in your colours.

Anyone can already save a theme and share it by link. A public gallery turns every saved theme into a browsable, one-click-apply page — Thingtime's most demoable feature, out in the open.

Built on machinery that already ships: /api/v1/themes/shared + ?apply=<shareId> deep links, the sanitising resolveTheme(), and ThemeStudio's existing mini preset previews (extract the preview card, add a list mode). Apply routes through applyThemeDoc; ⭐ marks the viewer's active theme.
