Final test matrix

  • Clean logged-out context: create, edit, native preview, canonical export and normal import; zero private/account/public persistence.
  • Account/offline contexts: cold startup, local commit despite failed remote services, independent retries, reconnect and reviewed conflicts.
  • Boundary transitions: two accounts, two tabs, changed origin/data plane, logout, permission refusal and expired authority.
  • Failure paths: malformed JSON, missing dependencies/assets, invisible/overflow output, timeouts, exhausted quota and incomplete bytes.
  • Responsive native views: 1440×1000, 390×844 and 320px; exact text, bounds, crop and actual downloadable files.
